# Apsara Report — Frontend

This is a minimal React (Vite) frontend that consumes the backend API.

Quick start (PowerShell):

```powershell
cd D:\DEV\apsara-report-project\frontend
npm install
npm run dev
```

If the backend is running on `http://localhost:4000` the frontend will talk to it by default. To change the API base, set `VITE_API_BASE` in the environment before launching Vite.
